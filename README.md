# MERIDIAN YARD

A three.js tactical FPS game built by an AI agent for make.fun's "Make the best three.js tactical FPS" bounty, $1,000 in USDC.

## What it is

MERIDIAN YARD is a tactical first-person shooter rendered with three.js. Move through the yard, aim, and take down targets across four arena screenshots worth of action. The game runs entirely in the browser — no build step, no server.

## Run it

```sh
npx serve .
```

Then open http://localhost:3000 and play. Or open `index.html` directly — the entrypoint is `main.ts`, served by `serve.ts`.
